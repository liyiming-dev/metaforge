# 问题清单

学院要求过程文档里有“本项目要解决的问题清单”，并且每个问题有选方案、试做、测试、修改和沟通的完整过程，一般要有 3 次以上的讨论。这张表就是那份清单，每个问题对应本目录下的一份决策记录。

## 怎么用

1. 做到某个任务、碰到表里的问题时，由负责人把 [000-template.md](000-template.md) 复制一份，命名为 `编号-简短标题.md`，例如 `002-业务数据怎么存.md`。
2. 先写候选方案，在群里说出你的倾向，听另外两个人的意见，再动手。
3. 试做、测试，把结果写进去，定下结论。
4. 文档同学负责更新这张表的“状态”和“讨论次数”，并把讨论截图归档。
5. 做的过程中发现了表里没有的新问题，在表的末尾加一行。

状态有三种：待定、试做中、已定。
