## 4 时序图

### 4.1 保存模型（新建/修改）

```text
ModelEditPage.onSave()
  → validate()
  → metaApi.createModel() / updateModel()
  → request()
  → MetaController.createModel() / updateModel()
  → MetaService.createModel() / updateModel()
  → MetaValidator.validateModel(input, old, context)
  → MetaDefaults.normalize(input)
  → SchemaSync.create(model) / alter(old, model)
  → MetaRepository.insertModel() / updateModel()
  → MetaRegistry.reload()
  ← ModelDef
  → useModelStore.invalidate()
  → useMenuStore.reload()
```

### 4.2 查询一页数据

```text
ModelTable.load()
  → dataApi.search(model, {page,size,filters,sort})
  → request()
  → DataController.search()
  → DataService.search()
  → MetaRegistry.requireModel()
  → SqlBuilder.search()（生成 SELECT + COUNT）
  → NamedParameterJdbcTemplate.queryForObject(count)
  → NamedParameterJdbcTemplate.queryForList(select)
  → DataService.toRecords()
      → SqlBuilder.labelSelect() + queryForList()（每个多对一字段一条 IN）
  ← SearchResult
```

### 4.3 新建记录（含 B5 预留钩子）

```text
ModelForm.onSubmit()
  → 表单校验
  → dataApi.create(model, data)
  → DataController.create()
  → DataService.create()
  → fromBody()
  → beforeCreate()        ← B5 脚本钩子（现在是空方法）
  → requireRequired()
  → validateRelations()
  → SqlBuilder.insert()
  → NamedParameterJdbcTemplate.update()
  → afterCreate()         ← B5 脚本钩子（现在是空方法）
  → readBack()
  → toRecords()（批量拼 {id,label}）
  ← 完整记录
```

### 4.4 多对一下拉

```text
ManyToOneField.fetchOptions(keyword)
  → dataApi.options(model, {keyword, displayField, limit})
  → DataController.options()
  → DataService.options()
  → SqlBuilder.labelField()
  → SqlBuilder.options()
  → queryForList()
  ← OptionItem[]
```

## 5 活动图：新建一条记录

```text
开始
 → 打开表单 / 填字段
 → 前端表单校验
     ├─ 不通过 → 字段下提示 → 返回填写
     └─ 通过
 → POST /api/data/{model}
 → fromBody：未定义字段 400；类型/枚举/默认值处理
 → beforeCreate 钩子（B5）
 → 必填校验 → 不通过 → 400 + fieldErrors
 → 多对一目标存在校验 → 不通过 → 400 + fieldErrors
 → INSERT（参数绑定）
     ├─ 唯一约束冲突 → 409 + fieldErrors
     └─ 成功
 → afterCreate 钩子（B5）
 → 读回记录 + 批量 label
 → 返回 200 + 完整记录
```

## 6 画图时别写错的点

- 后端包名：`com.metaforge.meta`、`com.metaforge.data`、`com.metaforge.schema`、`com.metaforge.common`、`com.metaforge.health`。
- 前端组件名用文件名，不加 `Page` 以外的后缀；`ModelTable`、`ModelForm`、`ModelEditPage` 大小写和代码一致。
- B5 的 `ScriptEngine`、`SvcController`、`ScriptContext`、`DbAccess` 还没实现；架构图可以画成虚线“计划”，不要画成实线已完成类。
- 数据表统一 `md_` 前缀；备份表 `zz_` 前缀；元模型表是 `meta_module`、`meta_model`。
- 时序图里 `MetaService.createModel()` 的顺序是：校验 → 补默认 → 建表 → 存定义 → `registry.reload()`；`updateModel()` 是校验 → 补默认 → 改表 → 更新定义 → reload。
```
