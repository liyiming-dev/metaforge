# 测试

## 1 测试范围和方法

- **范围**：功能清单 FR-01 至 FR-29。其中 FR-11（AI 助手）是加分项，本期不做，不纳入测试。
- **方法**：黑盒测试，在部署好的真实系统上用界面手工执行，不直接改数据库。每条用例只通过点击菜单、填写表单、点按钮来完成；FR-26 至 FR-28 这类没有独立界面的特性，用能观察到的操作来验证。
- **测试对象**：MES 示例的两个模块、四个模型——生产管理（物料、产品、产品 BOM）、基础设置（编码规则）。
- **数据**：用例需要的数据由用例自己创建，前置条件里写明依赖哪条用例。用例之间不假设系统里已有数据。
- **环境**：Windows 11 专业版（10.0.26200）；Microsoft Edge 157.0.4341.60（备用 Google Chrome 156.0.8078.80）；前端 `http://localhost:5173`（Vite 开发服务器），后端 `http://localhost:8200`；后端 Spring Boot 4.0.5、OpenJDK 21.0.11；数据库 MySQL 8.0.44。
